एक जंगल में एक नटखट बंदर रहता था, जो हमेशा हाथी का मज़ाक उड़ाता था। हाथी चुपचाप सब सह लेता। एक दिन जंगल में आग लग गई। बंदर एक पेड़ पर फँस गया और डर से चिल्लाने लगा। तभी हाथी आया और अपनी सूँड से बंदर को सुरक्षित नीचे उतार लिया। बंदर को अपनी गलती समझ आ गई। उसने हाथी से माफ़ी माँगी।
सीख: किसी को कमज़ोर समझकर मज़ाक नहीं उड़ाना चाहिए।
